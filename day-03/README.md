# Day 3 - Resume Project (HTML)

## Overview
Today I built a personal Resume webpage using only HTML. This project helped me practice semantic HTML structure and real-world webpage layout.

---

## Topics Covered
- HTML Boilerplate
- Semantic Tags (`header`, `main`, `section`, `footer`)
- Headings (`h1` to `h3`)
- Paragraphs
- Lists (`ul`, `li`)
- Links (`a`)
- Basic page structuring

---

##  Project Description
This is a simple resume webpage that includes:

- Personal introduction
- Skills section
- Education details
- Projects
- Career goals
- Contact information

---

## What I Learned
- How to structure a professional webpage using HTML
- Importance of semantic tags for readability
- How to organize content into sections
- How to use links for email, phone, GitHub, and LinkedIn
